# Immersive Technology Accessibility Resources

A lightweight, accessible resource hub designed for deployment on GitHub Pages.

## What is included

- Responsive, accessible static website
- Keyword search
- Live filtering by:
  - technology
  - accessibility area
  - resource type
  - audience
- Featured user pathways for designers, developers, evaluators and researchers
- Curated starter resource collection
